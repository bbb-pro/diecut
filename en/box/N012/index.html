What are the default dimensions of box type N012?

How many cut and crease lines does box type N012 have?

The template contains 29 cut lines and 9 crease lines.

Can I change the dimensions of box type N012?

Yes. 3 parameters are adjustable, including l, w, d. The die-cut outline is recalculated on every change.
