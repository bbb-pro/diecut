Frequently asked questions

What are the default dimensions of box type Z012?

The default size is L 150 mm, W 100 mm, D 300 mm. The flat (unfolded) sheet measures 500 × 522 mm.

How many cut and crease lines does box type Z012 have?

The template contains 16 cut lines and 10 crease lines.

Can I change the dimensions of box type Z012?

Yes. 3 parameters are adjustable, including l, w, d. The die-cut outline is recalculated on every change.

Which export formats are supported?
