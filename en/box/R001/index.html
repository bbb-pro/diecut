What are the default dimensions of box type R001?

How many cut and crease lines does box type R001 have?

The template contains 28 cut lines and 8 crease lines.

Can I change the dimensions of box type R001?

Yes. 3 parameters are adjustable, including l, w, d. The die-cut outline is recalculated on every change.
