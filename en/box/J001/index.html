Frequently asked questions

What are the default dimensions of box type J001?

The default size is L 250 mm, W 100 mm, D 200 mm. The flat (unfolded) sheet measures 724 × 251 mm.

How many cut and crease lines does box type J001 have?

The template contains 18 cut lines and 8 crease lines.

Can I change the dimensions of box type J001?

Yes. 3 parameters are adjustable, including l, w, d. The die-cut outline is recalculated on every change.

Which export formats are supported?
