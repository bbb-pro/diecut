Frequently asked questions

What are the default dimensions of box type 0300?

The default size is L 300 mm, W 200 mm, D 50 mm. The flat (unfolded) sheet measures 822 × 315 mm.

How many cut and crease lines does box type 0300 have?

The template contains 48 cut lines and 16 crease lines.

Can I change the dimensions of box type 0300?

Yes. 3 parameters are adjustable, including l, w, d. The die-cut outline is recalculated on every change.

Which export formats are supported?
